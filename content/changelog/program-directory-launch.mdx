Affitor starts here: one place to find affiliate programs worth promoting. Search by name, sort by commission or popularity, filter by category and tag, and open a page for each program with its commission details.

- Light and dark theme.
- Works on phones, with a mobile sort menu.
- Pick which table columns you see; Affitor remembers your choice.

The directory became the Affitor Marketplace in June 2026, and old directory links now open it. [Browse the marketplace](https://affitor.com/marketplace)
