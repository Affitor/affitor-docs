The first version of the Affitor CLI is on npm. Create an affiliate program from your terminal and get its tracking script and API key.

```bash
npx affitor init
```

- `status` shows your program's health and recent events, and `test` sends a test click, lead or sale.

Programs created this way were not yet linked to a dashboard account. Browser sign-in, `programs` and `whoami` arrived in May.
