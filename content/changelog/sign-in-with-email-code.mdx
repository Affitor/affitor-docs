Sign in to Affitor, or create your account, with a six-digit code sent to your email at [affitor.com/login](https://affitor.com/login).

Until this week, using your email meant a password: you typed one to sign in, and to sign up you chose one, typed it twice and then clicked a verification link. Now your email gets a code instead. Google sign-in and sign-up work as before.

## How it works

- **Enter your email**: click **Email me a code** to sign in, or **Create account** to sign up.
- **Enter the code**: type or paste the six digits, and they submit themselves.
- **One code at a time**: a code works once, for 10 minutes, and a new one replaces it.

## Sign in

On [the sign-in page](https://affitor.com/login), enter your email and click **Email me a code**. **Check your email** shows where the code went. Type or paste the code from the email titled "Your Affitor sign-in code", and you are signed in. There is no button to press.

## Sign up

On [the sign-up page](https://affitor.com/signup), pick **I'm a brand** or **I'm a partner**, enter your email and click **Create account**. Enter the code and your account is ready, with no password to choose and no verification link to open.

The code works the same on both pages: if an account already uses that email, it signs you in; if none does, it creates one.

## If the code does not work

- **That code is wrong or has expired.** means the code was mistyped or is more than 10 minutes old. After five wrong tries, a code stops working.
- **Resend code** appears a minute after each send. After a wrong code, it reads **Send a new code**.
- **Use a different email** takes you back to the first step.

## Prefer a password?

On the sign-in page, **Use password** opens the email and password form, and **Email me a code instead** brings the code back.

## Conclusion

Signing in or up with your email now starts with a code; on the sign-in page, **Use password** still opens the password form. [Learn more on the sign-in page](https://affitor.com/login), and write to support@affitor.com with any question.
