Run `affitor init` in a Next.js project. The CLI detects the framework, installs the SDK, and adds the tracking code, showing you the diff before it writes anything.

```bash
npx affitor init
```

A server-side Node SDK ships alongside it, so you can record sales from your backend. Since June 2026 the SDK is published as `@affitor/sdk`.
