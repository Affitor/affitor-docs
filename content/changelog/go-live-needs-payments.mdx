A program goes live only when Affitor can count its sales, so partners are never sent to a program that cannot pay them.

## What Go live checks

- **Business:** a name and a website.
- **Commission:** what partners earn on a sale.
- **Payments:** Stripe connected, or one sale sent from your server. A test sale counts.

Click tracking shows its state on the same page but does not block Go live. A logo is no longer required.

## If something is missing

The Go live button stays off and each missing row links to the step that fixes it.
