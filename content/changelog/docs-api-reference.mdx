The docs are rebuilt for developers. A new **API Reference** tab covers every tracking endpoint, with pages on attribution and errors. Alongside it:

- an SDK reference and six integration guides (Next.js on its own or with Clerk, NextAuth or Supabase, Express, and Stripe);
- an integration guide for AI agents, and `llms.txt` for assistants that read the docs;
- a **For Partners** section;
- a machine-readable OpenAPI spec.
