We opened list.affitor.com, a community site for affiliate programs and agent skills. You could browse, search and star what you liked, and developers could read the same list with an API key or connect it to Claude so an assistant searched programs for them.

list.affitor.com was retired in June 2026 and now opens the [Affitor Marketplace](https://affitor.com/marketplace).
