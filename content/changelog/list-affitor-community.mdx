list.affitor.com is a community site for affiliate programs and agent skills. Browse, search and star what you like. Developers can read the same list with an API key, or connect it to Claude so an assistant can search programs for you.

list.affitor.com was retired in June 2026 and now opens the [Affitor Marketplace](https://affitor.com/marketplace).
