### New

- Brands with several programs switch between them from a program selector. A brand with no program yet is taken to create one.
- Auto-accept for partner applications is set per program.
- An early access sign-up on a refreshed landing page with an FAQ. That landing page has since been replaced.

### Fixed

- The first invoice of a subscription no longer pays the commission twice.
