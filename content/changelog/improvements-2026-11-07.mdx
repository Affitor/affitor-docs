### Improved

- In **Connect an AI tool**, the **Other** tab now has steps for Grok: add Affitor as a custom connector at grok.com/connectors, then sign in.
- In **Connect an AI tool**, the **Other** tab now has steps for Muse Code: add Affitor to `~/.config/muse/settings.json`, then run `muse mcp login affitor` in your terminal.
- AI tools can read `/agents`, `/switch`, `/privacy`, `/terms`, `/legal/refer-program` and `/legal/subprocessors` as Markdown: add `.md` to the address or send `Accept: text/markdown`.
- AI tools can read category pages such as `/ai-video` as Markdown, with the first 50 programs the page lists: add `.md` to the address or send `Accept: text/markdown`.
- The **Commission Type** menu in a commission policy now offers CPS One-time, CPS Recurring and CPS Lifetime only.
- Policies that already use CPC or CPL are not changed.

### Fixed

- In **Connect an AI tool**, the brand steps for Claude, ChatGPT, Grok and Muse Code now say to pick your programs, then click **Allow**.
- The AI agents page at `/agents` lists all 13 tools, including `list_programs`, and says a brand connection reads the programs you choose when you connect.
- Team members with no brand or partner account of their own now land on their team's program after signing in, instead of **How will you use Affitor?**
- If your brand has no program yet, opening **Groups**, **Commissions** or another dashboard section takes you to creating your first program.
- A saved **Dashboard** link for a program you can't open now takes you to a program you can, or to setting one up if you have none.
- In Program settings, **Business** drafts the About text once per program in your browser, so reloading the page no longer asks for a new draft.
- Screen readers now announce when the totals on **Commissions** are updating.
- Program pages in the marketplace no longer show the program name, facts and **Apply to promote** button stacked in one spot for a moment while loading.
- Deleting an API key no longer fails. After you type the key's name to confirm, the key is deleted.
- Affitor now accepts the sign-in from Town and from Perplexity Enterprise, so they can finish connecting when you add Affitor's MCP server.
- If the database can't confirm a save, commission status changes, invoice settlement, payouts marked as sent and disputes now return an error and notify no one, instead of reporting success.
- For an inactive referral link, the hint from `POST /api/v1/track/click` now says the link or its program is not active, instead of saying the partner or brand turned it off.
