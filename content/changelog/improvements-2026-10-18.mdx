### New

- Docs now live at [affitor.com/docs](https://affitor.com/docs) and the blog at [affitor.com/blog](https://affitor.com/blog), with new comparisons of affiliate software and pricing.
- The hosted tracker and the click endpoint accept `?via=` as well as `?aff=`.
- A brand's server can pass the visitor's IP address as `visitor_ip` to `POST /api/v1/track/click`, with the program API key.
- An agent skill that finds an affiliate program and checks its terms.

### Improved

- **`affitor` 0.4.2 is on npm:** `affitor onboard` and `affitor whoami --json` exit with code 1 on failure, and it shows API key rotation notices.
- The tracker sends each partner click once. Brands that record clicks themselves can set `data-affitor-clicks="off"`.
- A paused program's public page answers "not found", like an archived one.
- Marketplace program pages are easier for search engines to read.
- A full pass that checked the docs against the product finished this week: errors, tracking, attribution, invoices, refunds and SDK snippets.

### Fixed

- Email sign-up keeps the name you typed.
- Links with `?mode=signup` open the sign-up form.
- Brand setup loads after a reload or a fresh sign-in.
- A program page shows its whole About section.
- The marketplace shows every featured program on every page and filter.
- A program goes live only through the go-live step, so a pause for an overdue invoice stays in place.
- Public pages describe first-click attribution the way the product works.
- **`affitor` 0.4.3:** `affitor status` and `affitor test` run with just an API key and leave out test data, generated tracker code uses `loadAffitor`, and `affitor setup stripe` points to the dashboard.
- `@affitor/sdk` 2.1.1 adds types for `getVisitorId` and consent.

### Security

- We tightened sign-in and access checks across the dashboard and the API.
