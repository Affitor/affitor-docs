date: 2025-12-11
type: feature
audience: [brands]
surfaces: [dashboard, tracking]
description: New brands see what is left to set up, and clear guidance when the tracking code is not installed yet.
---

New brands get a **Getting Started** checklist with the steps left: your program, commission tiers, the tracking code and your first partner. Until the tracking code is on your site, the dashboard says so and takes you to where to add it, instead of showing empty charts.
