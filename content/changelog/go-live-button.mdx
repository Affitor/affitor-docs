Your program goes live when you say so. A single **Go Live** button replaces automatic publishing, and the quick-start checklist next to it reflects what is really set up.

- **No Stripe required.** Record sales from your server with the tracking API.
- **Stripe per program.** Each program connects its own Stripe account.
