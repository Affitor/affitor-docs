### New

- A changelog page, with a Markdown version for AI agents.

### Improved

- Tracking a click on a disabled referral link answers `410 link_disabled`, so you can tell it apart from an error.
- Marketplace pages carry correct structured data for search engines.

### Fixed

- If you signed up with Google, you can set a first password through the emailed link.
- Partners auto-accepted into a program now get the approval notification.
- Programs created from the CLI pay the commission they were created with.

### Security

- We tightened sign-in, password reset and withdrawals.
