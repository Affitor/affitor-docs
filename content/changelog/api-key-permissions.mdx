Give each program API key its own permission, **Full access** or **Tracking only**, and turn a key off and on again without replacing it, in [API keys](https://affitor.com/brand/settings/api-keys).

Until this week, the API keys table showed Name, Created and Last used, a new key asked only for a name, and each key offered Rotate and Expire. Now every key has a permission you can change, and you can disable a key instead of expiring it.

## How it works

- **Two permissions**: **Full access** sends tracking events and reads your stats. **Tracking only** can send clicks, signups, sales and refunds.
- **Edit any time**: rename a key or change its permission. The key itself stays the same.
- **Disable and enable**: stop a key's calls, then turn it back on later.

## Create a key with a permission

Click **Create key**, enter a name and pick **Full access** or **Tracking only**. Full access is selected by default. Your new key appears once in **Copy your key**, so copy it before you click **Done**.

<Media src="/docs/changelog/api-key-permissions/create-key.png" alt="Create key with a name filled in and Full access or Tracking only to pick" />

Use Tracking only for a server that only reports events. If that key asks for your stats, the request is refused.

## Manage a key from its menu

The table shows **Name**, **Key**, **Permission**, **Last used** and **Created** for each live key. From the row menu:

- **View details**: the masked key, permission, last use and status.
- **Edit key**: a new name or permission, applied from the next call.
- **Disable key** or **Enable key**: a disabled key is marked **Disabled**, and its calls are refused until you enable it.
- **Rotate key**: a new key with the same name and permission. The old key stops right away.

<Media src="/docs/changelog/api-key-permissions/api-keys.png" alt="API keys with a Full access key, a Tracking only key and a Disabled key, each with its masked key and Permission" />

## Where to find it

Open the program menu, choose **Program settings**, then **Developers** › **API keys**. Owners and Admins of the program see this table.

## Conclusion

Each key now does only what you allow. [Learn more in API keys](https://affitor.com/brand/settings/api-keys), and write to support@affitor.com with any question.
