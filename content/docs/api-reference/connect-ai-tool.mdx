Add the Affitor MCP server to your AI tool, then sign in with your Affitor account. No API key needed. You will add the server, sign in on affitor.com, choose your programs and what the AI may do, and click **Allow**.

## Before you start

- An Affitor account with a program, or a program you joined as a partner.
- When you sign in, reading is always on, and you tick each write permission you allow.

## Server URL

```text
https://mcp.affitor.com/mcp
```

Every tool below uses this URL. For transport, sign-in and the full tool list, see the [MCP server reference](/docs/api-reference/mcp).

## Claude

Claude on the web and Claude Desktop.

1. Add the server in one click: [Add to Claude](https://claude.ai/customize/connectors?modal=add-custom-connector&connectorName=Affitor&connectorUrl=https%3A%2F%2Fmcp.affitor.com%2Fmcp).

Or add it by hand:

2. In Claude, open **Customize** › **Connectors**.
3. Click **+ Add**, then **Add custom connector**. Name it Affitor, paste the URL and click **Continue**.
4. Keep the detected sign-in settings. If Claude asks, pick **Register automatically** under **OAuth client**.
5. Click **Add** and sign in to Affitor.

On Team and Enterprise plans, an owner adds the connector in **Organization settings** › **Connectors**, and members click **Connect**.

**Check it works:** in a new chat, ask your AI tool "List my Affitor programs". It answers with your programs.

## ChatGPT

1. Go to [chatgpt.com/plugins](https://chatgpt.com/plugins), click the plus button, then **Add custom MCP server**.
2. Enter a name, and under **Connection** paste the URL.
3. Set authentication to OAuth, review the warning and click **I understand and want to continue**.
4. Click **Create as a plugin** and sign in to Affitor.

Your workspace's policy may limit who can add custom MCP servers.

**Check it works:** in a new chat, ask your AI tool "List my Affitor programs". It answers with your programs.

## Cursor

1. Add the server in one click: [Add to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=affitor&config=eyJ1cmwiOiJodHRwczovL21jcC5hZmZpdG9yLmNvbS9tY3AifQ%3D%3D).

Or add it by hand:

2. Add this to `~/.cursor/mcp.json`:

   ```json title="mcp.json"
   {
     "mcpServers": {
       "affitor": { "url": "https://mcp.affitor.com/mcp" }
     }
   }
   ```

3. In **Cursor Settings** › **MCP**, click **Connect** and sign in.

**Check it works:** in **Cursor Settings**, open **MCP**: affitor shows its tools. Then ask your AI tool "List my Affitor programs". It answers with your programs.

## Claude Code

1. Install the Affitor plugin (recommended):

   ```text
   /plugin marketplace add Affitor/claude-plugins
   /plugin install affitor@affitor
   ```

2. Open `/mcp`, pick affitor and sign in.

Or add the server by hand:

1. Run this in your terminal:

   ```bash
   claude mcp add --transport http affitor https://mcp.affitor.com/mcp
   ```

2. In Claude Code, type `/mcp`, pick affitor and sign in.

Add `--scope user` to use Affitor in every project.

**Check it works:** run `claude mcp list`: affitor shows `Connected`. Then ask your AI tool "List my Affitor programs". It answers with your programs.

## Codex

1. Run this in your terminal:

   ```bash
   codex mcp add affitor --url https://mcp.affitor.com/mcp
   ```

2. If no sign-in page opens, sign in with:

   ```bash
   codex mcp login affitor
   ```

**Check it works:** run `codex mcp list`: affitor is listed. Then ask your AI tool "List my Affitor programs". It answers with your programs.

## VS Code

GitHub Copilot in VS Code.

1. Add the server in one click: [Add to VS Code](https://vscode.dev/redirect/mcp/install?name=affitor&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Fmcp.affitor.com%2Fmcp%22%7D).

Or add it by hand:

2. Add this to `.vscode/mcp.json` in your workspace, or to the `mcp.json` of your user profile:

   ```json title="mcp.json"
   {
     "servers": {
       "affitor": { "type": "http", "url": "https://mcp.affitor.com/mcp" }
     }
   }
   ```

3. Start the server and sign in when VS Code asks.

**Check it works:** in Copilot Chat in Agent mode, ask your AI tool "List my Affitor programs". It answers with your programs.

## Gemini CLI

1. Run this in your terminal:

   ```bash
   gemini mcp add --transport http affitor https://mcp.affitor.com/mcp
   ```

2. In Gemini CLI, run `/mcp auth affitor` and sign in.

**Check it works:** run `/mcp list`: affitor shows its tools. Then ask your AI tool "List my Affitor programs". It answers with your programs.

## Perplexity

1. Open **Plugins** in the sidebar, or **Customize** › **Connectors** if you don't see Plugins.
2. Select **Add custom** › **Connector** › **Add MCP connector**, then **Remote**.
3. Enter a name, and under **MCP Server URL** paste the URL.
4. Under **Authentication** pick **OAuth** and under **Transport** pick **Streamable HTTP**. No Client ID or Client Secret is needed.
5. Check the acknowledgement box, click **Add**, then click the connector card and sign in to Affitor.

In an organization, members can add custom connectors only if an admin allows it. Perplexity on its Enterprise address, `enterprise.perplexity.ai`, cannot connect yet.

**Check it works:** in a new thread, ask your AI tool "List my Affitor programs". It answers with your programs.

## Other MCP clients

### Grok

1. Go to [grok.com/connectors](https://grok.com/connectors), click **New Connector**, then **Custom**.
2. Paste the URL and sign in.
3. Pick your permissions and programs, then click **Allow**.

On Grok Business, an admin adds the connector first.

### Any other MCP client

1. Add this to your client's MCP config:

   ```json
   {
     "mcpServers": {
       "affitor": { "url": "https://mcp.affitor.com/mcp" }
     }
   }
   ```

2. Restart the client and sign in when it asks.

Apps on your own computer connect through `http://127.0.0.1` or `http://localhost`. A web app connects only if Affitor accepts its return address; the [MCP server reference](/docs/api-reference/mcp) lists them.

**Check it works:** ask your AI tool "List my Affitor programs". It answers with your programs.

## What the AI can do

When you sign in, you choose the programs and what the AI may do. Reading is always on. Editing a program page (brands) or managing links (partners) is a box you tick. Money actions always happen in Affitor.

To see or remove a connection, brands open **Program settings** › **Developers** › **AI agents**; partners open **Integrations** from the account menu.
