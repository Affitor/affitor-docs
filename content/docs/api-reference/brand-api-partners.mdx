`GET /programs/{program_id}/partners` lists your program's partners, newest first, with all-time clicks, leads and sales and the money they earned in a date window. `GET /programs/{program_id}/partners/{partner_id}` reads one of them.

```http
GET https://api.affitor.com/api/v1/programs/{program_id}/partners
GET https://api.affitor.com/api/v1/programs/{program_id}/partners/{partner_id}
```

## Authentication

Send a live program API key as a Bearer token: `Authorization: Bearer <key>`. The key must have **Full access** and its read tick (**Can use the read API**) on. See [Brand API](/docs/api-reference/brand-api) for which keys can read.

## Parameters

| Parameter | In | Type | Required | Notes |
|---|---|---|---|---|
| `program_id` | path | string | Yes | The key's own program id, or me. |
| `partner_id` | path | string | Yes | A partner's id from the partners list. |
| `from` | query | string | No | First day (UTC, YYYY-MM-DD). Default: 29 days before to. A window is at most 366 days. |
| `to` | query | string | No | Last day (UTC, YYYY-MM-DD). Default: today. |
| `limit` | query | integer | No | 1 to 100, default 50. |
| `cursor` | query | string | No | next_cursor from the previous page; bound to this route, program and filters. It is an offset in a stable newest-first order: a row added while you page can appear twice, never be skipped. |

`partner_id` is for the single-partner read; `limit` and `cursor` for the list. This list is paged: pass `limit` (1 to 100, default 50) and, for the next page, the `next_cursor` of the previous answer as `cursor`. `next_cursor` is `null` on the last page. A cursor works only with the same route, program and filters.

### Fields

| Field | Type | Always present | Notes |
|---|---|---|---|
| `id` | string | Yes | The id of the partner in this program. Use it as `partner_id` here and in [Commissions](/docs/api-reference/brand-api-commissions). |
| `name` | string or null | Yes |  |
| `partner_code` | string or null | Yes |  |
| `group` | object or null | Yes |  |
| `joined_at` | string or null | Yes |  |
| `clicks_all_time` | integer | Yes |  |
| `leads_all_time` | integer | Yes |  |
| `sales_all_time` | integer | Yes |  |
| `from` | string | Yes | The first day of the window. |
| `to` | string | Yes | The last day of the window. |
| `earned` | list of Money object | Yes | Money earned in the window, one entry per currency. |
| `pending` | list of Money object | Yes | Money still pending in the window, one entry per currency. |
| `truncated` | Truncated | No | Present only when a text field was cut to 280 characters. |

## Errors

Errors use one shape with a `code` and a `request_id`. The codes this endpoint can return:

| Status | `code` | When |
|---|---|---|
| 400 | [`invalid_request`](/docs/api-reference/brand-api-errors#invalid_request) | A parameter is unknown, repeated, malformed or out of range. `param` names it |
| 401 | [`invalid_key`](/docs/api-reference/brand-api-errors#invalid_key), [`wrong_key_type`](/docs/api-reference/brand-api-errors#wrong_key_type), [`key_revoked`](/docs/api-reference/brand-api-errors#key_revoked) | The key is missing, unknown, not a live program key, disabled or retired |
| 403 | [`insufficient_permission`](/docs/api-reference/brand-api-errors#insufficient_permission) | The key is tracking-only or its read tick is off |
| 404 | [`not_found`](/docs/api-reference/brand-api-errors#not_found) | The program in the path is not the key's own program, or the partner is not in the program |
| 500 | [`internal_error`](/docs/api-reference/brand-api-errors#internal_error) | Retry with backoff; if it keeps failing, send us the `request_id` |
